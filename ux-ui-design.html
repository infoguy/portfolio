Project 1

Visit Taniti: Tourism Website

An eight-page tourism website taken from research and wireframes through a high-fidelity prototype to a working HTML/CSS build.

Role: UX/UI designer and front-end developerTools: Figma, HTML, CSS, JavaScriptScope: 8 pages, responsive

The problem

A fictional island destination needed a site that helps first-time visitors answer four questions quickly: where to stay, what to do, how to get around, and how to book.

The approach

I mapped the visitor's journey and structured the site into eight pages: Home, Where to Stay, Dining & Nightlife, Things to Do, Tours & Sights, Getting Here & Around, Travel Info & FAQ, and Book Your Trip. I built the high-fidelity prototype in Figma, with reusable component states for the navigation and forms, then coded it as a static site with one shared stylesheet and filter chips on the listings pages.

The result

A responsive site where every page answers one visitor question, with a consistent palette and type system carried from prototype to code.

Project 2

CourseBuildtools: Canvas Automation Suite

A set of web and desktop tools that let instructional designers build Canvas courses, quizzes, and rubrics from Word documents in minutes instead of hours.

Role: Product designer and developerTools: Python, Flask, HTML/CSS, Canvas REST APIUsers: Instructional designers and faculty

The problem

Building a Canvas course by hand means hundreds of repetitive clicks: creating assignments, setting dates, converting quizzes, pasting rubrics. Designers spend their time on data entry instead of design.

The approach

I started with myself as the first user, mapped the repetitive tasks, and designed simple single-purpose interfaces: upload a Word file, pick a course, press go. Each tool uses the Canvas REST API under the hood so the interface stays simple while the work happens in the background.

The result

Quiz conversion, module creation, rubric import, and assignment scheduling that used to take an afternoon now take minutes. The tools are the basis of CourseBuildtools, a service for colleges and ID agencies, with walkthrough videos for each tool.
